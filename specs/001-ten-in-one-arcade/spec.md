# 功能規格：霓虹十合一小遊戲廳

## 1. 背景與目標

建立一個可直接在瀏覽器開啟的繁體中文單頁小遊戲網站，讓使用者不需註冊、不需下載，就能在同一個整潔的遊戲大廳中挑選並遊玩十款短回合遊戲。

主要成功條件是：使用者在首次載入後能迅速理解入口、在桌面與手機上都能完成遊戲操作、每款遊戲都有明確的開始／重玩／結束狀態，且最高分在同一瀏覽器中可以保留。

## 2. 使用者故事

### US1：瀏覽與啟動遊戲（優先級 P1）

身為想快速放鬆的訪客，我希望在一個清楚的遊戲大廳看見十款遊戲的差異，並用一次點擊開啟其中一款。

**驗收條件：**

- 首屏可看見網站標題、遊戲總數、推薦遊戲與「開始挑戰」入口。
- 遊戲大廳列出恰好十張遊戲卡，每張包含圖示、名稱、短說明、難度或回合資訊。
- 點擊卡片或推薦入口後，遊戲面板在同一頁開啟，不需重新導向或重新整理。
- 遊戲面板可由明確的關閉或返回控制收起，回到遊戲大廳。

### US2：完成十款可玩的遊戲（優先級 P1）

身為玩家，我希望十款遊戲各自有不同的核心玩法，且都能在短時間內開始、完成或重玩。

**驗收條件：**

- 反應脈衝：等待目標變色後點擊，顯示反應時間並拒絕過早點擊。
- 記憶翻牌：翻開牌面、配對八組圖示，完成時顯示步數與耗時。
- 霓虹貪食蛇：可用方向鍵／WASD 或觸控方向按鈕移動，吃到目標增加分數，撞牆或自身時結束。
- 迷你踩地雷：在 5×5 棋盤中揭開安全格、標記地雷，揭開地雷時結束，完成安全格時勝利。
- 2048 輕裝版：使用方向鍵或面板按鈕滑動方塊，相同數字合併，無法移動時結束。
- 打地鼠：在限時回合內點擊隨機出現的目標，命中增加分數，時間結束後顯示結果。
- 色彩辨識：根據顯示文字的實際色彩作答，完成十題並顯示正確數量。
- 井字對決：玩家與電腦輪流落子，三子連線時結束，平局也能明確辨識。
- 完美堆疊：在移動中的方塊與堆疊區重疊時按下按鈕，保留重疊部分並逐步加分，完全錯開時結束。
- 數字密碼：猜測 1–50 的隨機數字，每次提供高低提示，猜中或用盡八次機會時結束。
- 每款遊戲至少提供「重新開始」或等效的新局控制。

### US3：掌握分數與狀態（優先級 P1）

身為玩家，我希望知道目前分數、回合進度與自己的最佳紀錄，完成後能決定是否再玩一次。

**驗收條件：**

- 遊戲面板在遊戲進行中顯示與該玩法有關的狀態，例如分數、時間、步數、回合或提示。
- 遊戲結束時顯示結果訊息、最終分數，以及「再玩一次」控制。
- 各款遊戲的最佳分數以瀏覽器本機儲存，在重新載入後仍可讀取；若瀏覽器拒絕儲存，遊戲仍可正常進行。
- 大廳能顯示至少一個整體玩家統計，例如已完成遊戲數或最佳紀錄數。

### US4：在不同裝置上舒適遊玩（優先級 P1）

身為使用手機或鍵盤的玩家，我希望控制項容易點擊、焦點清楚，且畫面在窄螢幕上不會橫向溢出。

**驗收條件：**

- 互動元素有可辨識的鍵盤焦點樣式，按鈕與遊戲格可用鍵盤操作（依玩法提供方向鍵、Enter、Space 或 Tab）。
- 觸控遊戲使用足夠大的按鈕與 `pointer` 事件，不依賴滑鼠懸停才能理解或操作。
- 主要版面在 360px 寬度至桌面寬度間可重排，無不必要的橫向捲動。
- `prefers-reduced-motion` 使用者不會被非必要的動畫干擾。

## 3. 非功能需求

- NFR1：不使用帳號、後端資料庫、外部 API 或外部圖片；網站在靜態檔案伺服器上即可運作。
- NFR2：所有使用者可見文案、操作提示與錯誤提示使用繁體中文（台灣）。
- NFR3：核心介面使用語意化 HTML、按鈕與標籤，遊戲畫布提供相鄰的文字狀態與替代操作。
- NFR4：首次載入不需等待第三方資源；程式保持可讀、可在 Node.js 進行語法與規則測試。
- NFR5：公開 repository 不得包含憑證、`.env`、個人 token 或建置快取。

## 4. 不在範圍內

- 多人連線、排行榜伺服器、登入與跨裝置同步。
- 音效、音樂、廣告、付款、社群分享與內容管理後台。
- 第二條以上的網站路由或遊戲編輯器。

## 5. 介面文案與狀態原則

- 主要品牌句：`十款小遊戲，剛好一局。`
- 入口按鈕：`開始挑戰`、`看全部遊戲`。
- 進行中狀態提供可行動提示，例如 `等它變亮再點`、`用方向鍵或下方按鈕移動`。
- 結束狀態以結果、原因與下一個動作為優先，不使用只表達成功／失敗的模糊訊息。
